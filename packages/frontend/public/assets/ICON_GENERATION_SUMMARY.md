## 🎨 设计特点

### 严格遵守设计规范

✅ **配色方案**
- 仅使用黑白灰色系
- 色值范围：#000000 - #FFFFFF
- 无任何彩色元素

✅ **风格要求**
- 简洁像素风格
- 矩形和直角为主
- 避免大圆角（>8px）
- 使用硬阴影

✅ **视觉识别**
- 每个图标都有独特的视觉特征
- 同类型图标具有家族相似性
- 不同等级图标有明显递进关系

### 图标设计亮点

#### 资源图标
- **一产**：强调原始形态（矿石多边形、气体气泡、晶体结构）
- **二产**：突出加工特征（金属板材、化学容器、电路板）
- **三产**：体现高科技感（复杂结构、多层次、科技元素）
- **四产**：表现稀有性（能量效果、特殊符号、防护措施）

#### 建筑图标
- **采矿设施**：以工具为主（钻头、吸气、激光、泵）
- **加工设施**：突出工厂形态（烟囱、储罐、管道）
- **建造设施**：展现制造过程（吊车、机械臂、打印机）

#### 船舶图标
- **战舰**：从小到大递进，武器装备逐渐增多
- **探索船**：天线和探测器是核心元素，等级越高越复杂
- **工程船**：工具臂和货舱是特征，等级递进明显

## 💡 使用示例

### 基础使用
```vue
<template>
  <img src="/assets/icons/resources/primary/iron_ore.svg" alt="铁矿石" />
</template>
```

### 使用路径常量
```typescript
import { ResourceIcons, getResourceIcon } from '@/assets/iconPaths';

// 方式1：直接使用常量
const ironOreIcon = ResourceIcons.IRON_ORE;

// 方式2：使用函数获取
const copperPlateIcon = getResourceIcon('copper_plate');
```

### 预览所有图标
```vue
<template>
  <IconPreview />
</template>

<script setup>
import IconPreview from '@/components/IconPreview.vue';
</script>
```
